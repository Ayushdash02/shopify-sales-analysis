## 📌 Project Overview

**Shopify Sales Analysis** is a Business Intelligence project developed using **Microsoft Power BI and DAX** to analyze e-commerce sales performance, customer behavior, product trends, geographic distribution, and customer retention.

The interactive dashboard transforms sales data into meaningful business insights to support performance monitoring and data-driven decision-making.
